# Language Learning Assistant with Individual Progress Tracking

## My interpretation of the brief
This project is about building a language learning app that tracks individual student progress and adjusts practice sets automatically. The main focus is writing database functions and procedures that look at past mistakes and time intervals to decide which words or exercises a user should practice next.

## Why I am a good fit for this project
I am  learning a foreign language while studying engineering, so I know how helpful personalized practice and spaced repetition are. Building the selection logic directly inside the database is a great opportunity for me to practice back-end logic and database procedural programming.

## Relevant experience and background
- **Databases & SQL:** I have a good understanding of relational database design, table relationships, and writing queries from my coursework.
- **Back-End Development:** Experience with object-oriented programming (C#) and connecting databases to simple application interfaces.
- **Tools:** Comfortable using Git for version control, SQL tools, and Visual Studio.

## Proposed approach
I will start by designing a clean relational database schema to hold vocabulary, exercise history, and user attempts. Then, I will write database procedures to calculate priority scores for words based on past accuracy. Finally, I will connect a simple interface so users can log in, practice, and see their progress update in real time.

## Initial plan
1. Design the database tables, relationships, and user progress rules.
2. Create test data to simulate student practice history.
3. Write and test database procedures to pick the next practice words.
4. Build a basic user interface to show practice sessions and results.
5. Test query performance, refine indexes, and complete project documentation.

## Additional information
I will manage my code changes using Git and keep track of my project tasks using a public Trello board.
