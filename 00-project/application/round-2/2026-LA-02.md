# League of Legends Match Data Warehouse  

## My interpretation of the brief
The goal of this project is to collect match stats from the Riot Games API, clean up the data, and store it in a structured database. The main challenge is handling a lot of match data efficiently, setting up automatic data loading, and writing database queries to analyze how players, champions, and game updates perform over time.

## Why I am a good fit for this project
I want to get better at working with databases and handling larger sets of data. Match statistics are structured and interesting to work with, so this project is a great way for me to practice real database design, learn how to handle API data, and write better SQL queries.

## Relevant experience and background
- **Databases & SQL:** I have a good foundation in database design, joining tables, and writing basic and intermediate SQL queries from my coursework.
- **APIs & Data:** I know how to use scripts to fetch data from APIs, read JSON formats, and save that information into a database.
- **Tools:** I regularly use Git for version control, SQL tools, and Visual Studio for my programming projects.

## Proposed approach
I will first write a script using Python or C# to fetch raw match data from the Riot Games API and save it in a staging table. Then, I will design a clean database schema (using facts and dimensions) to organize players, champions, and match results. After loading the data into the database, I will write SQL queries to track champion win rates and player performance, and make sure those queries run smoothly.

## Initial plan
1. Look at the API data and decide how to organize the database tables.
2. Write a script to fetch match data from the Riot Games API and save it.
3. Build the database structure and set up the process to load new data regularly.
4. Write SQL queries to find interesting stats like champion win rates and patch trends.
5. Test how fast the queries run, optimize indexes if needed, and write the project documentation.
